# 컨테이너 검수 보고서(EIR) 표준 양식

> 본 문서는 항만 컨테이너 외관 검수 결과를 정리하는 **EIR(Equipment Interchange Receipt)**
> 표준 양식이다. 보고서 자동 생성 시 이 양식의 구성·항목·문체를 따른다.

## 1. 보고서 구성 항목

보고서는 다음 순서와 항목을 반드시 포함한다.

1. **기본 정보**: 이벤트 ID, 컨테이너 번호, 촬영/처리 시각, 검수 결과(정상/손상), 분석 모델
2. **위험도 요약**: Risk Score(0~100), Risk Level(HIGH/MEDIUM/LOW), 탐지 손상 개수
3. **손상 내역**: 손상별 유형(구멍/찌그러짐/녹슴), 심각도(경미/중간/심각), 신뢰도, 위치
4. **종합 소견**: 검수 결과 전체 요약 (2~4문장)
5. **손상 평가**: 손상의 위치·정도·구조적 영향에 대한 평가
6. **권고 조치**: 필요한 후속 조치(재사용/수리/반출 등)
7. **재사용 판정**: USABLE / REPAIR_NEEDED / REJECT 중 하나와 그 근거

## 2. 문체 및 작성 규칙

- 모든 서술 항목은 **한국어**로, 객관적이고 간결한 문장으로 작성한다.
- 제공된 탐지 결과(detections)에 근거하며, 없는 손상을 추정·추가하지 않는다.
- 심각도·유형은 표준값을 사용한다(아래 표준값 참고).
- 수치(Risk Score, 신뢰도)는 근거로 인용하되 과장하지 않는다.

## 3. 표준값

- 손상 유형(class): `hole`(구멍), `dent`(찌그러짐), `rust`(녹슴)
- 심각도(severity): `low`(경미), `medium`(중간), `high`(심각)
- 검수 결과(inspection_result): `normal`(정상), `damage`(손상)
- 재사용 판정(reuse_decision): `USABLE`(재사용 가능), `REPAIR_NEEDED`(수리 후 재사용), `REJECT`(사용 불가)

## 4. 재사용 판정 기준

| 판정 | 조건 | 대표 조치 |
|---|---|---|
| `USABLE` | 무손상이거나 경미(low) 손상 위주, Risk Level LOW | 추가 조치 없이 재사용 |
| `REPAIR_NEEDED` | 중간(medium) 수준 손상, Risk Level MEDIUM | 해당 부위 수리 후 재사용 |
| `REJECT` | 관통/구조적(high) 손상, Risk Level HIGH | 반출/정비 절차, 재사용 보류 |

## 5. 양식 예시 (작성 톤 참고)

```
[컨테이너 검수 보고서 - EIR]

1. 기본 정보
 - 컨테이너: MSKU7654321 / 검수 결과: 손상 / 처리 시각: 2026-07-13T02:35:26Z

2. 위험도: Risk Score 90.5 / Level HIGH / 손상 2건

3. 손상 내역
 - 구멍(hole), 심각(high), 신뢰도 0.88, 위치 하-우
 - 찌그러짐(dent), 중간(medium), 신뢰도 0.64, 위치 중-좌

4. 종합 소견
 하단 우측에 관통성 구멍이 확인되며 구조적 손상으로 판단된다. 중앙 좌측의
 찌그러짐도 동반되어 전반적 위험도가 높다.

5. 손상 평가
 구멍은 화물 보호·방수 기능에 직접 영향을 주는 심각 손상이며, 즉시 조치가 필요하다.

6. 권고 조치
 구조적 손상으로 재사용을 보류하고, 정비소 반출 및 상세 점검을 권고한다.

7. 재사용 판정: REJECT
 관통성 구멍(high)으로 컨테이너 무결성이 훼손되어 사용 불가로 판정한다.
```
