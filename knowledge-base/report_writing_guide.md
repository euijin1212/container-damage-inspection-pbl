# 컨테이너 검수 보고서 작성 지침

> EIR 보고서의 각 항목을 작성할 때 참고하는 실무 지침이다. 손상 유형별 표현,
> 심각도 해석, 권고 조치 문구의 기준을 제공한다.

## 손상 유형별 설명 기준

### 구멍(hole)
- 관통·천공 손상. 컨테이너 무결성(방수·화물 보호)에 직접 영향.
- 심각도가 high 이면 구조적 손상으로 보고 재사용을 보류(REJECT)하는 것이 원칙.
- 표현 예: "관통성 구멍으로 방수 기능이 훼손됨", "화물 오염·유실 위험".

### 찌그러짐(dent)
- 외력에 의한 변형. 위치와 깊이에 따라 영향이 다름.
- 문틀/모서리 변형은 개폐·적재에 지장을 줄 수 있어 중요도가 높음.
- 표현 예: "측면 패널 변형", "구조 강도 저하 우려".

### 녹슴(rust)
- 표면 부식. 대부분 경미하나 진행 시 강도 저하로 이어질 수 있음.
- 단독 경미(low) 손상은 대체로 재사용 가능(USABLE) 또는 관찰 대상.
- 표현 예: "표면 부식 관찰", "방청 처리 권고".

## 심각도(severity) 해석

| 심각도 | 의미 | 일반 조치 |
|---|---|---|
| low(경미) | 표면적, 기능 영향 거의 없음 | 관찰 또는 재사용 |
| medium(중간) | 눈에 띄는 손상, 기능 영향 가능 | 수리 후 재사용 검토 |
| high(심각) | 구조적/관통성 손상 | 즉시 조치, 재사용 보류 |

## 권고 조치 문구 가이드

- **USABLE**: "추가 조치 없이 재사용 가능합니다." / "정기 점검 시 재확인 권고."
- **REPAIR_NEEDED**: "해당 부위 수리 후 재사용을 권고합니다." / "수리 완료 후 재검수 필요."
- **REJECT**: "구조적 손상으로 재사용을 보류하고 정비소 반출을 권고합니다." /
  "상세 점검 및 수리 견적 산정이 필요합니다."

## 복합 손상(여러 건) 작성 기준

- 가장 위험한 손상을 먼저 서술하고, 나머지를 부가적으로 언급한다.
- 종합 소견은 개별 손상의 합이 아니라 **컨테이너 전체 상태**를 기준으로 판단한다.
- Risk Level 은 개별 손상이 아닌 종합 점수를 따른다.

## 금지 사항

- 제공되지 않은 손상·수치를 만들어내지 않는다.
- 검수 결과와 모순되는 판정을 내리지 않는다(예: high 손상인데 USABLE).
- 불필요한 추측성 문장, 과장된 표현을 피한다.
